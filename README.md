# apr-croissant
.deb packages for Linux users for En Croissant

To use:
Run this in your terminal:
```bash
wget https://raw.githubusercontent.com/Gabyface910/apt-croissant/refs/heads/main/en-croissant_0.15.0_arm64.deb
# Replace 'arm64' with your processor. Use 'arm32' for ARM32, 'arm64' for ARM64, and 'amd64' for AMD64.
sudo apt update
```
